# Code of conduct

Be respectful and assume good faith. Critique code and designs, not people. Harassment, insults, and personal attacks are not tolerated in issues, pull requests, discussions or any other project space.

Maintainers may edit or remove contributions, and block participants, that break these rules.

To report a problem privately, use the repository's private vulnerability reporting form (the **Security** tab, then **Report a vulnerability**) and say that it is a conduct report. Reports are read only by the maintainers.
