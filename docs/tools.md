# tailkeeper tools

Generated by `tailkeeper docs` from the tool registry. Do not edit by hand.

43 tools. Each is an MCP tool (name below) and a CLI command. MCP advertises alpha tools only with `--enable-alpha` (or `mcp.enableAlpha`); the CLI runs them without it.

Parameters carry their MCP argument names. On the CLI each is a kebab-case flag (`staleDays` is `--stale-days`), and a tool's only required text parameter may be given as a plain argument instead.

Unless the configuration sets `personalData` to `show`, personal data in results is masked: fields listed as masked whole keep their first character, plus the domain of an email address; in every other untrusted field, email addresses are masked the same way and public IP addresses are cut to their network, except in fields listed as never masked and in fields listed as having only their email addresses masked. The error messages of tool calls are masked like untrusted fields, without pseudonyms: an error echoes what the caller typed, and a pseudonym beside a guess would confirm it. With a privacy key, each masked identifier and email address in a result ends in its pseudonym ([p:…]), and filters take pseudonyms; while masking is on, filters that would confirm a guessed value are refused.

## acl

### `acl_get`

Show the tailnet policy file, a page at a time, as the API returned it.

- CLI: `tailkeeper acl get`
- Tier: read; stage: ga
- OAuth scopes: `policy_file:read`, `devices:core:read`, `devices:posture_attributes:read`
- API operations: `GET /tailnet/{tailnet}/acl`, `GET /tailnet/{tailnet}/settings`
- Note: A display copy, not the file to edit: email addresses are masked unless personalData is show (addresses and CIDRs stay whole), and line ends are shown as LF. With personalData show, bytes, sha256 and etag describe the policy as the API returned it; otherwise bytes and sha256 describe the policy as shown, every page joined, and etag is left out, so none of them can confirm a guessed address. The whole policy, comments included, goes to whoever reads the result.
- Untrusted output fields: `externalLink`, `policy`
- Email addresses masked unless `personalData` is `show`, the rest kept (configuration): `policy`
- Untrusted but never masked (configuration): `externalLink`

| Parameter | Type | Required | Description |
|---|---|---|---|
| `fromLine` | integer |  | first line of the page, from 1 (default 1); use nextLine from the previous page |
| `maxBytes` | integer |  | page size: bytes of the page once masked, escaped and encoded as JSON text, 1024 to 4194304 (default 153600); a line longer than the page is refused with the size to ask for |

### `acl_test`

Test whether a source can or cannot reach destinations under the live policy, without changing it.

- CLI: `tailkeeper acl test`
- Tier: read; stage: ga
- OAuth scopes: `policy_file:read`, `devices:core:read`, `devices:posture_attributes:read`
- API operations: `POST /tailnet/{tailnet}/acl/validate`
- Note: One source per call, against the live policy only, with no posture attributes; SSH rules are not tested. A masked value (one with …) cannot be tested: ask the user for it. A source or destination Tailscale cannot resolve fails the test, with its reason. The CLI exits 9 when the test fails.
- Untrusted output fields: `failures[].errors`, `failures[].src`, `warnings`
- Email addresses masked unless `personalData` is `show`, the rest kept (configuration): `failures[].errors`, `failures[].src`, `warnings`

| Parameter | Type | Required | Description |
|---|---|---|---|
| `accept` | string[] |  | destinations src must reach, as host:port (tag:prod:22, 100.64.0.5:443, [fd7a:115c:a1e0::5]:22) |
| `deny` | string[] |  | destinations src must not reach, as host:port |
| `proto` | string |  | IP protocol, a name such as tcp, udp or icmp, or a number from 1 to 255; icmp needs port 0 |
| `src` | string | yes | the source: a user's login, group:name, tag:name, a host alias or a tailnet address; never a masked value |

## webhooks

### `webhook_get`

Get one webhook endpoint.

- CLI: `tailkeeper webhooks get`
- Tier: read; stage: ga
- OAuth scopes: `webhooks:read`
- API operations: `GET /webhooks/{endpointId}`
- Untrusted output fields: `creatorLoginName`, `endpointHost`
- Masked whole unless `personalData` is `show`: `creatorLoginName`
- Untrusted but never masked (configuration): `endpointHost`

| Parameter | Type | Required | Description |
|---|---|---|---|
| `id` | string | yes | webhook endpoint ID |

### `webhooks_list`

List webhook endpoints (secrets never shown; URLs reduced to host and path hash).

- CLI: `tailkeeper webhooks list`
- Tier: read; stage: ga
- OAuth scopes: `webhooks:read`
- API operations: `GET /tailnet/{tailnet}/webhooks`
- Untrusted output fields: `webhooks[].creatorLoginName`, `webhooks[].endpointHost`
- Masked whole unless `personalData` is `show`: `webhooks[].creatorLoginName`
- Untrusted but never masked (configuration): `webhooks[].endpointHost`

No parameters.
