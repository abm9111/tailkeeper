# OAuth scopes

Generated by `tailkeeper docs --scopes` from the tool registry. Do not edit by hand. `tailkeeper scopes` prints the same list.

tailkeeper needs one OAuth client with read scopes only. Grant every scope below that is not marked alpha to run every tool; grant fewer to run fewer tools (each tool's scopes are in `docs/tools.md`). A tool in the third column reads part of its result with each of its scopes: it returns what the scopes you grant cover and says what it could not see, but fails with `scope_missing` if you grant none of them. A tool in the fourth column runs without the scope and uses it for one feature, named in brackets: granting it enables that feature, and the tool says what it left out when the scope is missing. `tailkeeper doctor` reports which scopes a configured client lacks (an optional one as information, not a failure), and fails if it holds a write scope.
